# План реализации пересчёта счетов за месяц

**Цель** — распределять стоимость рейса с точностью до копейки, показать бухгалтеру результат пересчёта и применить его по подтверждению.

**Архитектура** — один расчёт долей рейса используется в карточке и в счетах. Предпросмотр и применение строятся на одном расчёте периода. Применение сравнивает расчёт с сохранёнными счетами и записывает изменения в одной транзакции.

**Стек** — PHP 8.2+, PDO SQLite и jQuery. Для интеграционных проверок достаточно PHP CLI и базы, созданной из SQL в памяти.

**Источники** — [условие задания](task.html#L216) и [решения по расчёту и счетам](RESULTS.md).
