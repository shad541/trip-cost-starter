# Рейсы и счета

Небольшая система учёта рейсов сборных грузов и счетов клиентам.

## Запуск

Нужен PHP 8.2+ с расширением `pdo_sqlite`.

```bash
php bin/reset-db.php
php -S localhost:8000 -t public
```

Открыть http://localhost:8000.

То же через Docker:

```bash
docker run --rm -it -p 8000:8000 -v "$PWD":/app -w /app php:8.4-cli \
    sh -c "php bin/reset-db.php && php -S 0.0.0.0:8000 -t public"
```

`php bin/reset-db.php` пересоздаёт базу `data/app.sqlite` из `data/schema.sql` и `data/seed.sql`. Так можно вернуть
исходные данные в любой момент.

## Что внутри

| Папка | Что в ней |
|---|---|
| `public/` | Страницы, API (`public/api/`), скрипты и стили |
| `lib/` | Подключение к базе, общие функции, расчёт счетов |
| `data/` | Схема и данные |
| `bin/` | Служебные скрипты |

## Страницы

| Страница | Адрес | Для чего |
|---|---|---|
| Рейсы | `index.php` | Журнал рейсов: куда, когда, на какой машине, сколько стоит |
| Карточка рейса | `trip.php?id=` | Грузы клиентов в рейсе и доля каждого клиента в стоимости |
| Счета клиентов | `invoices.php` | Сохранённые счета, их суммы, статусы и даты отправки и выгрузки |
| Счета за месяц | `billing.php` | Предпросмотр и применение пересчёта за выбранный месяц |
| Счёт | `invoice.php?id=` | Из каких рейсов сложилась сумма счёта |
| Загрузка машин | `load_report.php` | Отчёт для логистов: насколько загружена машина по весу и какую часть веса занимает каждый клиент |
| Выгрузка счетов в 1С | `export_1c.php` | Файл для бухгалтерии: отправленные счета, которые ещё не выгружены |

## Правило пересчёта

Стоимость всего рейса делится между клиентами по объёму, если у всех грузов объём больше нуля. Если хотя бы у одного груза объём равен нулю или отсутствует, стоимость всего рейса делится по весу. Копейки распределяются по наибольшим дробным остаткам. При равенстве приоритет у меньшего ID клиента. Подробности в [RESULTS.md](RESULTS.md).

Откройте «Счета за месяц», выберите месяц, нажмите «Показать» и проверьте суммы до и после пересчёта. Кнопка «Применить» запрашивает подтверждение. Пересчёт сохраняет номера счетов, статусы и даты отправки и выгрузки. Корректировка данных у клиентов и в 1С выполняется отдельно.

Карточка рейса запрашивает `GET /api/trip_split.php?trip_id=11`. Экран «Счета за месяц» использует `GET /api/billing_preview.php?period=2026-10` для предпросмотра и `POST /api/billing_apply.php` с полем формы `period` для применения.

## Тесты

Для запуска из корня проекта нужен PHPUnit 11. Тесты загружают исходные данные в SQLite в памяти. Рабочая база `data/app.sqlite` в тестах не используется.

```bash
phpunit
```

Подходит и PHAR PHPUnit 11. Запустите его из корня проекта командой `php /путь/к/phpunit-11.phar`.

Проверки покрывают выбор веса или объёма, распределение всех копеек, предпросмотр без записи, создание недостающего счёта, повторное применение, сохранение истории отправки и выгрузки и откат при сбое записи.
